## Описание
Прототип in-memory базы данных для учета книг. Реализован на Python с поддержкой CRUD-операций и управлением таблицами.


## Функциональность
- Добавление, чтение (с фильтрацией), обновление и удаление записей
- Создание новых таблиц и просмотр списка таблиц
- Валидация ввода и обработка ошибок
- Консольное меню на русском языке

## Запуск
python -m src.db
