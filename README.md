## Описание
In-memory СУБД на Python с ООП-архитектурой для учета книг. Поддерживает CRUD-операции, фильтрацию, сортировку и управление таблицами.

## Функциональность
- Создание, чтение, обновление, удаление записей
- Фильтрация записей по полям
- Сортировка по выбранному полю (возрастание/убывание)
- Создание и просмотр таблиц
- Валидация ввода и обработка ошибок
- Консольный интерфейс на русском языке
- Покрытие тестами >80%

## Запуск
python -m src.db

# Запустить тесты
python -m pytest tests/ --cov=src --cov-report=term
